## Mapping status and gaps

The table links each feature to its owning module. API and database links are module-level indexes; they are not proof of a feature-specific operation or approved table ownership. The current coverage audit identifies 23 feature IDs without a direct feature-to-API contract. Do not fill those gaps by inventing endpoints. The database module map is schema discovery only.

For `ACC-01` and `ACC-02`, the [Customer Accounts LLD](../03-Modules/Customer_Accounts/LLD.md), [API contracts](../05-APIs/Customer_Accounts.md), and [edge cases](../03-Modules/Customer_Accounts/Edge-Cases.md) now define distinct flows, table mapping, and feature-specific tests. Other module links remain a navigation baseline and require the feature-level review identified in [Coverage report](Coverage-Report.md).

All development tasks are proposed and not tracked in an issue system. Proposed tests are not executed tests.
