Edge-case coverage

Scenario IDs are stable across related views. Product screens offer relevant situations through What if something goes wrong? with plain-language explanations; Review tools retains technical scenario selection. Loading, empty, session and permission states explain unavailable actions. Network loss retains the current task and blocks unsuccessful mutations. Specialized scenarios alter the domain view and/or its submitted outcome. Choosing a condition does not silently supply an approval. See per-platform verification for the distinction between implemented conditions and tested behavior.
