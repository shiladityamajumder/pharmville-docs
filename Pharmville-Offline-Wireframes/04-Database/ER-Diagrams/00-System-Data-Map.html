What this map shows

Pharmville's checked-out database snapshot contains 24 schemas, 268 tables, 4,485 columns, and 1,476 declared foreign keys. The map below shows representative business-domain dependencies backed by one or more declared foreign keys. Arrows point from the schema that owns the referencing (child) column to the schema containing its referenced (parent) key; they do not grant access or establish service write ownership. The cross-domain reference register lists every observed cross-schema pair.
