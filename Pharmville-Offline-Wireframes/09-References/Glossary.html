Short Pharmville engineering glossary

Term Plain meaning
HLD / LLD Architecture overview / detailed implementation plan
P / M / O Prescription-required, non-prescription medicine and other product classification
SKU Exact sellable item, including strength/form/pack variant
OTP / MFA One-time verification code / an additional proof beyond password
API / DTO Software request contract / validated input or response shape
UUID / BIGINT Publicly stable identifier / numeric internal database key
PK / FK / UNIQUE / CHECK Row identity / cross-table reference / duplicate blocker / valid-value rule
RLS / RBAC Database row filtering / role-based permissions
Idempotency Repeating the same action does not duplicate its business effect
Outbox Durable event written with a transaction for safe later delivery
POS Store billing/inventory system, here Techsmith
COD Cash on delivery, separate from collected/deposited money truth
Reconciliation Comparing local records against authoritative provider or physical evidence
RPO / RTO Maximum accepted data loss / restoration duration target
UAT Business users verify the delivered software meets approved workflows
Scope Which customer, patient, site or business action someone is permitted to access
