Pharmville interactive wireframes — Offline Edition

No installation needed. Extract this complete folder from the ZIP, then open index.html in a modern browser. Keep the assets/ and documentation directories alongside it. No Node.js, npm, network connection or localhost server is required.

This is a static HTML/CSS/JavaScript export of the existing Pharmville interactive prototype. It includes the existing customer, staff, pharmacist, warehouse, rider, finance, support and operations screens, with fictional shared demo data stored locally in this browser. It does not connect to backend services or accept real transactions.

Explore

Start from Choose Experience, then select Mobile App, Website, or Complete Business Journeys. The Review tools option contains scenario controls and links to included offline technical references.

Privacy and sharing

Use fictional test data only. Demo state stays in your browser storage for this file; the bundle does not transmit data to a server. To return to the starting state, use Review tools → Reset demo data.

Compatibility

Tested with Chromium opening file:// directly. Most current desktop browsers should work, but storage behavior for locally opened files can vary by browser and policy. If a browser blocks local scripts or storage, try opening the extracted file in Chrome or Edge.
