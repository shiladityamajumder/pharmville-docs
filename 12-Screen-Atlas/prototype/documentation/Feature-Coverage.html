Coverage boundaries

  • Covered by interaction/state: 23
  • Covered by screen: 70
  • Blocked by an open decision: 16
  • Backend-only, with no direct screen: 1

No feature is assigned a future phase merely from its database table. Warehouse/rider/optional launch questions remain the original owner decisions. CSV import and TSV export are explicit prototype format approximations; native Excel file parsing/creation is not claimed. Local code simulates idempotency and safety gates for review; it does not implement production authentication, medical eligibility or payment processing.
