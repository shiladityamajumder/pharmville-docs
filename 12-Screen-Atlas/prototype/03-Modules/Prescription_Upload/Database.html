Prescription Management database contract

Structure validated; business write assignment Proposed. Patient/prescription linkage; shared file infrastructure controls object storage and Pharmacist Review owns clinical decisions. Read access or a contract surface does not confer write ownership. Exact operation transactions/DTO columns are in APIs; shared audit/outbox/idempotency writes are owner-coordinated infrastructure.
