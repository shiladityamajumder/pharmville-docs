Authority and proposals

pharmville_schema.sql is authoritative structure. Schema-Catalog.json, Table-Register.json, table pages and ER diagrams are derived references. npm run validate:database checks structure in both directions. python3 scripts/validate-database.py --fresh re-executes the SQL in an independent private cluster and compares catalogs.

The master-data inventory, permission assignments, runtime login provisioning, module write-owner decisions, provider contracts and future capabilities remain planning decisions. Their proposed state does not alter constraints or authorize production activation. No evidence-backed approved requirement was found missing from the effective SQL; API fields identified as proposals remain separately recorded in planning decisions.
